How it works

Data

Every 2026 session via FastF1: qualifying, race results, and each driver's long-run practice pace (consistent 4+ lap stints, safety-car laps removed).

Model

A ridge regression predicts each driver's finishing position from grid slot, qualifying gap, long-run pace and championship points. It predicts position, not "win", because 300 finishing positions teach more than 14 winners.

Simulation

20,000 races: predicted position + random noise, random DNFs, and a safety car in some races that shuffles the order. Win % = how often each driver finishes first.

Calibration

The noise level is not guessed. It's the value whose podium odds best matched real 2026 results. Calibrating on winners alone overfit to a predictable season and made the model overconfident.

Built with Python (FastF1, pandas, scikit-learn). Not affiliated with Formula 1.
