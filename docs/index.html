How it works

Data

Every 2026 session via FastF1: qualifying, race results, and each driver's long-run practice pace (consistent 4+ lap stints, safety-car laps removed). Pace is compared within each session, because day and night sessions run at very different speeds, and then combined.

Model

A ridge regression predicts each driver's finishing position from grid slot, qualifying gap, long-run pace, championship points and, since v2, whether a strong car is starting out of position. It predicts position, not "win", because 300+ finishing positions teach more than a handful of winners.

Simulation

A Monte Carlo simulation of 20,000 races: predicted position + random noise, random DNFs, and on street circuits a likely safety car that shuffles the order. Win % = how often each driver finishes first.

Calibration

The noise level is not guessed. It's the value whose podium odds best matched real 2026 results. Calibrating on winners alone overfit to a predictable season and made the model overconfident.

v2 (after Baku): v1 underrated Antonelli, who went from P16 to P5 in the Mercedes. Adding "fast in practice but starting back" didn't help, because midfield practice pace is too noisy. Adding "strong car starting behind its usual slot" did help: podium log-loss improved from 1.048 to 1.030 over 11 races. It's a small, honest gain. Big comebacks are rare, so the model still stays cautious about them. A gradient-boosting model was much worse, because it overfit ~300 rows.
